# Bike_rental_project
Final Project: Can historical bike usage and weather data be used to accurately forecast short-term (hourly) bike rental demand using time-series models?
Models used:
1. SARIMA (univariate time-series)
2. SARIMAX (time-series with exogenous variables)
Dataset: UCI Bike Sharing Dataset (hour.csv) Target: cnt (hourly bike rental demand)
